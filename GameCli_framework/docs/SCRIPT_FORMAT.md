# GameCLI Script Format

`script.json` is the only story file the GameCLI runtime plays. It is generated by the editor from the project graph and must not include editor-only nodes, canvas coordinates, AI settings, novel import source data, or provider secrets.

## Top-Level Fields

Required fields:

- `schema_version`
- `game_id`
- `title`
- `entry_scene_id`
- `scenes`

Optional fields:

- `loading_animation`
- `characters`

Example:

```json
{
  "schema_version": "1.1.0",
  "game_id": "rain_station",
  "title": "Rain Station",
  "entry_scene_id": "scene_opening",
  "loading_animation": { "kind": "default" },
  "characters": [
    { "character_id": "alice", "name": "Alice", "aliases": ["A"] }
  ],
  "scenes": []
}
```

## Loading Animation

GameCLI supports three loading animation modes:

```json
{ "kind": "default" }
```

```json
{ "kind": "video", "video_asset_id": "boot_video" }
```

```json
{
  "kind": "image_sequence",
  "image_asset_ids": ["boot_frame_001", "boot_frame_002"],
  "frame_duration_ms": 1000
}
```

`default` uses the built-in circular boot animation. `video` references a packed `video` asset. `image_sequence` references packed `ui` assets and defaults to 1000 ms per image when the frame duration is omitted.

## Scenes

Scenes contain:

- `scene_id`
- `title`
- `summary`
- `chapter`
- `tags`
- `commands`
- optional `next_scene_id`
- optional `is_ending`
- optional `ending_id`

`entry_scene_id`, `next_scene_id`, choice targets, and conditional jump targets must point to existing scenes. Scripts with `schema_version: "1.0.0"` remain readable; new exports use `1.1.0`.

## Commands

These are the GameCLI `script.json` command types and runtime command fields.

Supported command types:

- `dialog`
- `narration`
- `hide_dialog`
- `background`
- `show_image`
- `sprite`
- `choice`
- `state_update`
- `conditional_jump`
- `animation`
- `bgm`
- `sfx`
- `camera`
- `wait`

## Choice Commands

Choices are visible player branches. Each choice may include `conditions`, and GameCLI shows only choices whose conditions all pass:

```json
{
  "type": "choice",
  "choices": [
    {
      "choice_id": "ask_truth",
      "text": "Ask for the truth",
      "target_scene_id": "scene_truth",
      "conditions": [{ "key": "trust", "operator": "greater_or_equal", "value": 3 }]
    }
  ]
}
```

If a choice command has no visible choices after filtering, playback continues to the next command instead of waiting on an empty choice panel.

## Background Commands

Background commands may include `background_fit`:

```json
{
  "type": "background",
  "background_id": "station_rain",
  "background_fit": "stretch",
  "transition": "fade"
}
```

Supported display modes are `stretch` (`background-size: 100% 100%`), `contain`, and `cover`. Missing or invalid values are treated as `stretch` so older scripts keep the all-stretched default.

## Show Image Commands

`show_image` blocks story progression while a key image is shown above a dimmed, blurred player:

```json
{
  "type": "show_image",
  "image_id": "clue_photo",
  "image_fit": "contain",
  "caption": "The key is engraved with the old dormitory number.",
  "alt": "An old numbered key",
  "backdrop_opacity": 0.62,
  "backdrop_blur_px": 12
}
```

The player dismisses it by clicking the overlay or pressing Enter, Space, or Escape. The overlay fades for `220ms * motionScale`, then the next command executes. Auto and skip modes remain paused while the image is visible. Missing image assets render a dismissible error placeholder.

## Hide Dialog Commands

`hide_dialog` clears the current dialog or narration panel and immediately continues:

```json
{ "type": "hide_dialog" }
```

It does not hide playback controls, choices, sprites, or other player UI. Place a blocking event such as `wait`, a blocking animation, or a focused image after it when the dialog should remain hidden for a visible amount of time.

## State Update Commands

State updates support typed values:

```json
{
  "type": "state_update",
  "key": "loop_count",
  "operation": "add",
  "value": 1,
  "value_type": "number"
}
```

`value_type` may be `boolean`, `number`, `text`, or `list`. `add` and `subtract` operate on numbers, `toggle` flips a boolean-like value, and `append` / `remove` update list variables.

## Conditional Jump Commands

Conditional jumps are automatic branches:

```json
{
  "type": "conditional_jump",
  "condition": { "key": "loop_count", "operator": "less_than", "value": 3 },
  "target_scene_id": "scene_loop",
  "else_target_scene_id": "scene_after_loop"
}
```

When the condition passes, GameCLI jumps to `target_scene_id`. When it fails, GameCLI jumps to `else_target_scene_id` if provided; otherwise it continues to the next command. This supports loops by jumping back to an earlier scene.

## Sprite Commands

Sprite commands control character standees:

```json
{
  "type": "sprite",
  "character_id": "alice",
  "sprite_id": "alice_default",
  "position": "center",
  "layer": 4,
  "visible": true,
  "animation": "fade_in",
  "animation_config": {
    "kind": "move",
    "phase": "enter",
    "duration_ms": 520,
    "easing": "ease-out",
    "direction": "left",
    "blocking": false,
    "display_name": "Left slide in"
  }
}
```

`layer` controls standee depth and accepts integers from `-1000` to `1000`; larger values render in front. Missing or `null` values inherit the same character's current layer, while a new character defaults to effective layer `0`. Equal layers retain appearance order, and changing a layer does not move the standee horizontally.

`animation_config.kind` accepts `none`, `fade`, `move`, `tween`, and `preset`. `phase` accepts `enter`, `exit`, and `emphasis`.

For `visible: false` with an exit animation, GameCLI keeps the standee mounted until the animation completes, then removes it. If `blocking` is `true`, the story waits for the animation before advancing.

Legacy `animation` strings such as `fade_in`, `slide_in_left`, and `shake` still run and are mapped to equivalent runtime animation effects.

## Tween Keyframes

`animation_config.kind: "tween"` can define keyframes:

```json
{
  "kind": "tween",
  "phase": "enter",
  "duration_ms": 680,
  "easing": "ease-out",
  "keyframes": [
    { "offset": 0, "opacity": 0, "x": -80, "scale": 0.98 },
    { "offset": 1, "opacity": 1, "x": 0, "scale": 1 }
  ]
}
```

Supported animated properties are `opacity`, `x`, `y`, `scale`, `rotate`, `blur`, and `brightness`. Offsets must be numbers between `0` and `1`.

## Animation Commands

Animation commands play explicit performance effects:

```json
{
  "type": "animation",
  "animation_id": "sprite_tween",
  "target": "sprite:alice",
  "params": {
    "duration_ms": 520,
    "easing": "ease-out",
    "keyframes": [
      { "offset": 0, "opacity": 0 },
      { "offset": 1, "opacity": 1 }
    ]
  },
  "blocking": false
}
```

Sprite targets can be `sprite:selected`, `sprite:all`, or `sprite:<character_id>`. Character-specific targets must be traceable from `characters`, dialog commands, or sprite commands.

## Validation

GameCLI and editor export validation check:

- duplicate or missing scene IDs;
- invalid entry, next-scene, choice, and conditional jump targets;
- missing or mismatched asset references;
- invalid loading animation references;
- invalid sprite animation config values;
- untraceable `sprite:<character_id>` animation targets.

Errors stop import/export. GameCLI should show the validation message rather than silently falling back to a different story structure.
## Speaker Focus

```json
{
  "speaker_focus": {
    "enabled": true,
    "scale": 1.05,
    "duration_ms": 220
  }
}
```

The runtime applies this relative scale only when the current dialog character has a visible sprite. Narration restores all sprites to their base scale.

## Cutscene Video

```json
{
  "type": "video",
  "video_id": "opening_movie",
  "video_fit": "cover",
  "fade_in_ms": 500,
  "fade_out_ms": 500
}
```

Video commands block normal story advancement, play with sound, and continue automatically after completion. Double-click reveals a five-second hold-to-skip control.
