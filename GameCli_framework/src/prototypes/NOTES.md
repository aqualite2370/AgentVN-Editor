# 快捷菜单动效原型

问题：游戏客户端的快捷菜单在点击后，如何让三点入口自然形变成工具容器，并让动作在同一层渐显？

入口：`npm --prefix GameCli_framework run dev` 后打开 `http://127.0.0.1:6868/?prototype=quick-menu&variant=A`。

方案：

- A「胶囊展开」：沿用客户端三点小按钮作为右侧锚点，外层直接从圆形裁切形变成短胶囊；动作按钮不再套卡片或额外行容器，只保留同一层图标并整体渐显。
- C「侧栏抽屉」：沿用客户端三点小按钮向上拉伸成窄工具轨；动作直接挂在容器上，不再使用行卡片或标题层，按钮按 42ms 队列逐项渐显。
- D「底部托盘」：容器向左下展开为双排托盘，按钮全部挂载后一起渐显，底部安全轨为 X 保留点击空间。
- E「紧凑浮条」：容器横向拉成浅浮条，七个按钮以紧凑图标栏一起渐显。

待用户选择方案或混合组合后，删除未选方案和本原型切换器，再将胜出方案重写进正式 `PlaybackControls`。

正式客户端同步约束：

- preview 模式与普通运行模式都只显示 7 个真实快捷动作，不再注入预览徽标按钮。
- 收缩入口使用 `PrecisionIcon` 的三点几何；桌面在 46–50px 范围随布局高度适配，移动端保持 44px 触控目标。
- 展开面板宽度同时尊重皮肤布局宽度、真实动作内容宽度与当前视口可用宽度，避免窄屏压缩或横向溢出。
