# AgentVN 操作知识：当前编辑器能力与边界

这是按实际源码入口核对的操作资料，不是测试通过证明。当前候选版号、源码功能、安装版验收和模型验收必须分别看待；不要把设计文档中的未来能力说成已发布功能。没有资料支持的操作应明确说不确定。问询只能解释和打开设置入口，不能替作者写入工程。不要发送凭据、工程文件、剧情文本或未授权素材。

## layout-background | Ren’Py 控件背景图、颜色与继承

当前源码的主页文字入口：选项→游戏客户端→Ren’Py→标题主页，选择“标题信息”。右侧“主页文字”可分别打开/关闭标题和版本，不隐藏背景，也不修改工程名称与版本。点击“自定义标题文字”或“自定义版本文字”后编辑；留空就不显示该段文字，点击对应“恢复…工程继承”才重新沿用工程信息。隐藏后仍保留自定义文字。选择内建菜单按钮后，“菜单按钮文字”只改文案，保留原动作。保存布局后再保存工程包；游戏导出使用当前活动布局，新标题文字设置需要Runtime 0.26.0。此段是源码操作说明，具体安装版的能力以其版本与实际验收记录为准。

入口：顶部“选项”→“游戏客户端”→布局类型“Ren’Py”。在中间实际预览点击要改的按钮/容器，或从左侧控件列表选择；右侧“当前控件 · 外观”就是单控件设置。
“当前控件背景图”可选工程内图片；没有图片时先点“导入图片”。“清除图片”移除当前配置。图片如何显示：铺满并裁切（cover）、完整显示（contain）、拉伸铺满（stretch）。按钮可先选普通、悬停/焦点、选中、禁用状态，再设置该状态的图片和颜色。不要把整个页面背景、控件背景和编辑器画布背景混为一谈。
普通模式无需写代码。右侧可调背景颜色、文字颜色、边框、字号、内容留白、间距、圆角；默认只修改当前控件。字段显示“当前控件覆盖”“继承普通状态”“页面/主题继承”，并提供恢复继承。共享按钮主题在共享样式中单独设置，不能为了改一个按钮批量改全局。
如果进阶代码覆盖某个属性，界面会标出“代码覆盖”与来源；在代码区修改该值或移除相应覆盖，不能以图形设置悄悄擦掉代码。改完点“保存布局”，再预览并导出核对。AgentVN 与 Ren’Py 两套布局分别保存。
关键词：background image、button、panel、底图、背景图片、容器贴图、Ren'Py、Ren’Py、进阶布局。
实现：RuntimeLayoutDesigner、RenpyControlAppearanceEditor、RenpyRuntimePreview。

## game-aspect | 游戏画面比例与移动端底栏

当前源码入口：选项→游戏客户端→顶部“画面比例”，可选16:9、16:10、4:3。先选择要修改的AgentVN或Ren’Py布局，再选择比例并“保存布局”；两套布局分别保留比例。旧工程未配置时仍为16:9，不自动改动原有控件。

玩家入口：游戏内“设置→显示→画面比例”，两种布局均可选择工程默认、16:9、16:10、4:3，立即生效。作者配置只是默认值；玩家选择按游戏保存在本机，重启后保留，不写入卡带或剧情存档。选择“工程默认”可恢复作者画幅而不改变其它偏好；“恢复默认”会同时重置全部玩家设置。
这是游戏画面的比例，不是窗口分辨率、图片适配方式或编辑器缩放。窗口与设备不匹配时等比留边，不拉伸画面；桌面预览、移动预览和当前布局导出的卡带使用同一配置。逻辑画面依次为1280×720、1280×800、1280×960。
Ren’Py快捷栏相对实际游戏画面底边及安全区定位；留边在游戏画面之外，因此不要求按钮贴住设备物理屏幕的边缘。AgentVN快捷菜单继续沿用对白框上方的定位规则。布局测试中手动移动的控件不代表默认位置。
保存工程包保留两种布局；卡带只导出当前布局。新比例配置需要Runtime 0.27.0，旧Runtime应明确拒绝。不据源码说明声称已完成安装版或Android真实设备验收。
关键词：宽高比、画面比例、aspect ratio、16比9、16比10、4比3、移动端贴底、安全区、留黑边、横屏画幅。

## layout-code | 普通图形设置和进阶 HTML/CSS

入口：选项→游戏客户端，先选“Ren’Py”，再勾选其右侧独立“进阶”复选框。普通设置仍是基础；右侧“当前控件 · HTML / CSS”只覆盖当前选中控件。
点击“为当前控件启用代码覆盖”，编辑 HTML 结构和 CSS 样式。必须且只能保留一个 `<slot name="content"></slot>`，由原生控件提供文字和功能内容；原动作、可访问名称和命中区继续由 AgentVN 管理。
支持受限 div/span/p/img、功能插槽及白名单类名和样式。不能执行 JavaScript、Python、任意页面逻辑、自定义 screens.rpy 或外部网址；不能创建另一套按钮动作。状态不能改变尺寸或命中区。代码解析失败逐项显示原因，预览保留最近有效效果，无效代码不能写入已保存布局或导出内容。发布导出读取最后保存的有效布局，不会把尚未保存的无效代码当作导出结果。切换工作区会保留本次编辑会话中按工程和布局隔离的草稿；这不代表未保存草稿能跨进程重启恢复。
取消“进阶”仅暂停此覆盖层的效果，保留代码和图形基础；重新勾选恢复。已有自定义组件不因关闭代码覆盖而消失。“移除当前控件代码覆盖”才删除该控件覆盖。HTML/CSS、两套布局和资源保存在工程包中，游戏只消费当前活动布局的有效结果。
关键词：高级模式、advanced、code override、HTML、CSS、代码覆盖、图形属性冲突。
实现：RuntimeLayoutTypeControls、ControlPresentationEditor、controlPresentation。

## gui-pack | GUI 资源包的入库、修订与范围应用

入口：选项→游戏客户端→Ren’Py→“GUI资源包库…”。
先选择 ZIP 文件或资源目录（目录扫描只在桌面版提供），查看扫描结果、图片缩略图/尺寸、字体、静态参数、用途/状态映射、来源和问题列表。确认授权后点击“确认入库，不修改工程”。入库只保存本机独立资源包，尚未改变工程界面。
在本机库点击“预览并选择应用”，打开应用对话框。在“资源包应用范围”选择“当前Ren’Py布局”“单个页面”或“单个控件”。选择页面或控件范围后，用“目标页面”选择页面；选择“单个控件”后，再用“目标控件”选择按钮/容器，用“目标控件状态”选择普通、悬停 / 焦点、选中或禁用。这里通过应用对话框内的选择项指定目标；普通外观编辑中点击预览选控件是另一条操作路径。
例如只给一个按钮的悬停状态换图：选择“单个控件”→“目标页面”→“目标控件”→“目标控件状态”的“悬停 / 焦点”。在该图片的“导入操作”选择“复制为新素材”，将“游戏界面用途”设为“当前控件背景”；仅复制素材不会绑定外观。勾选需要的参数，核对所选素材、影响范围和素材授权后点击“确认应用到当前工程”，最后“保存布局”。现有进阶代码覆盖同一外观属性时，需在对应代码区核对覆盖来源。
所有范围都复制新素材到工程；不替换其它控件或另一布局共用的原素材字节。入库和取消不能修改工程；应用后个人库与工程互不联动。已有参数默认不勾选覆盖，切换范围后要重新核对。重新导入可另存新包或从旧修订建立新修订，原修订与人工修改保持。
支持 gui.rpy 中白名单静态参数、图片和字体。无法解析的表达式、自定义 screens.rpy、Python 逻辑明确列为未支持，不运行代码；不要声称“完整执行 Ren’Py 工程”。不安全路径、链接、重名文件和压缩超限会阻止导入。
关键词：GUI package library revision、界面包、模板图片、资源包管理、应用没有生效。
实现：RenpyGuiImportWorkbench、guiPackLibrary、guiPackApplication、renpy_gui_import。

## components | 组件库、ZIP 分享和安全组件

入口：选项→游戏客户端内的自定义组件库。组件可单个或多选导出 ZIP，包含版本清单、受限结构、样式和依赖素材；不包含工程 ID、会话或凭据。
导入先扫描、校验和预览，再进入本机个人库；冲突另存副本。使用时复制到工程，之后库原件与工程实例互不影响。不要把组件 ZIP 当作可执行网页。
组件 HTML/CSS 转成结构化节点；动作和字段绑定只来自 AgentVN 白名单，素材必须来自组件包或本次授权。脚本、外部网址、路径穿越、重复路径、非法样式、异常压缩包会被拒绝；失败不能发布部分组件。
实现：CustomComponentLibraryPanel、personalComponentLibrary、customComponentMarkup、RuntimeCustomComponentLayer。

## project-save | 分工程 .vnproj 保存目录和工程重开

入口：顶部“选项”→“项目设置”→工程包保存目录。桌面版可选择目录、查看当前路径、恢复默认。目录按工程 ID 保存在本机；切换工程切换对应目录，另一台电脑打开 .vnproj 不携带原机器路径。
未设置时使用系统下载目录。已选目录失效或无写权限要明确报错并重选，不能静默回退；同名连续保存产生新文件，不覆盖旧包。此目录只控制便携工程 .vnproj，不改变卡带、Windows 游戏和 Android APK 输出目录。
浏览器只能沿用下载行为，网页不能控制浏览器下载文件夹。工程包包括工程图、两套布局、代码和资源；本机个人库、会话和凭据不等于工程包内容。保存失败不能宣称已经落盘；重新打开实际文件验证。
实现：ProjectSettingsPanel、editorPreferencesStore、EditorToolbar、projectBundle、原生工程包写入接口。

## game-export | 预览、卡带、Windows 和 Android 导出

入口：顶部预览用于校验后启动外部 GameCLI；节点预览是另一条实时预览路径，不能代替外部玩家验收。顶部发布/导出中选择 .vncart 卡带或 Windows/Android 独立游戏。
导出前检查缺失引用、占位素材、入口场景、分支目标及环境。待补资源提示并不保证所有文件字节已验证；无头像、无立绘、停止音乐等合法配置不应当被要求补齐。可选创作建议不等于必补依赖。
.vncart 是玩家游戏包，不是作者工程包；它移除 AI 密钥和作者内部状态，只带当前活动布局和游戏依赖。Windows 导出有便携/安装包；Android 需要通过正确版本的 .avnenv 依赖检测、工具链和签名配置，不依赖开发者 D 盘路径。用户版 Windows 安装器采用 EXE，不新增 MSI 要求。
导出完成后应在目标平台安装并实际运行，检查画面、输入、存档及资源是否正常；导出成功本身不保证所有设备兼容。
实现：ExportCartridgePanel、exportCartridge、standalonePackage、runtimePackage。

## ai-modes | 问询、创造、授权和会话

入口：顶部 AI。问询解释操作并引用资料，没有写入工具，不修改工程。创造模式是独立会话和工作台：先授权具体控件、选择组件或授权工程素材，再在隔离草稿里构建、校验、真实预览、审核差异并合并。
Agent 能力由本次模式与授权生成，不可任意读取工程文件、工程图、密钥或未授权资源。创造工具调用成功不等于结果已写入工程。合并要校对基线，冲突不覆盖新修改；排除不想合并的项后批量应用，最后用工程正常保存流程落盘。
当前源码支持模型一次返回多个受限工具调用：整批先检查参数与授权，再按顺序执行；总计最多12次工具调用，最终提交须为末项。校验和预览等待所属编辑器的实际回执，取消后不继续执行；非法批次不执行，也不自动重发收费请求。这是源码能力说明，冻结安装版及真实模型验收另行记录。
工作台支持会话历史、归档/删除、全局进程与队列、取消和构建期间工程锁；其它工程的结果不能混入当前工程。实际模型会话、工具请求、受控响应和安装版验证应分别说明，不伪造已执行。
实现：AssistantChatPanel、AssistantCreationWorkbenchStudio、creationAgent、assistant_creation_queue。

## novel | 小说导入、解析悬浮窗和结果定位

入口：顶部小说导入→导入文本→检查/配置解析任务→进度与结果审核→导入节点。解析会调用配置的模型，暂停、继续、重试、取消的真实结果以任务状态为准。
缩略卡片保留状态和进度，可拖动、展开、最小化和隐藏显示；最小化或关闭任务展示不取消后端任务。通过顶部小说入口恢复查看。位置和任务恢复按工程隔离，工程切换不展示旧工程任务。
查看结果应返回编辑工作区并定位当前任务导入的节点，不能泛化跳到任意 imported 节点。章节补写保持已有节点、边和线路 ID，不把重复导入变成重复剧情。
实现：NovelProcessTaskWorkbench、NovelTaskCard、novelImportStore、importToGraph。

## dialogue | 普通对白、NVL、气泡、存档与回滚

呈现模式优先级是节点显式设置→角色默认→工程默认；旁白没有角色继承，工程默认普通对白。布局决定外观，不因切换皮肤改写剧情模式。
普通对白与气泡长文本先缩小到可读下限，再分页。NVL 按句累积，使用明确清页指令；页面容纳不下时翻页，不能无限缩小整页文字。分支预留空间；菜单往返不清空累积页；新场景、清页或离开模式才清空。
气泡默认跟随可见发言立绘，支持偏移或屏幕锚点；角色离场使用安全位置。姓名容器和头像外观在客户端布局中分别设置，头像默认在姓名容器左边。
快存为独立类别，保留最近六条，快读确认后选择最近有效记录；不占手动/自动槽位。Windows 独立内嵌游戏存档使用真实 EXE 旁 saves，不可写时明确报错，不静默回退 AppData。迁移旧档需要确认且保留源档、不覆盖冲突。存档、读档、回滚恢复模式状态而不重复添加对白或触发语音。
实现：DialogPresentationControls、StoryEngine、DialogBox、runtimeStore、desktopSaveManager。

## hide-ui | 游戏画面隐藏与恢复操作界面

游玩中，AgentVN 展开快捷菜单后点击“隐藏”；Ren’Py 底部九项单行快捷栏直接点击“隐藏”。键盘 H 也可隐藏。
隐藏对白、姓名容器、头像、NVL、气泡、分支选项、自定义剧情控件和快捷操作，场景与音频按原规则继续。自动与快进暂停，恢复后还原原模式。
轻触或点击画面、H、Escape 可以恢复；Android 返回先关闭最上层确认框，再恢复隐藏界面。这一次恢复操作不能同时推进或选择剧情。隐藏期间分支与NVL累计内容不丢失。
隐藏仅为当前游玩会话的临时显示状态，不是玩家偏好，不写入存档；读档、重启或离开剧情安全恢复。不要将它与作者脚本的 hide_dialog 演出命令混为一谈。
实现：StoryPlayer、RenpyQuickBar、runtimeStore、runtimeSystemBack。

## opening-container | 片头全屏、居中容器与跳过

在入口节点检查器或工程设置中的“用户开屏动画”选择视频或多图序列。“片头容器”可选全屏、居中尺寸；画面适配可选完整显示、裁切铺满、拉伸。居中宽高为视口的20–100%，外层黑底始终全屏遮挡。更换媒体保留容器设置；默认线条动画不使用这组媒体参数。旧工程缺省维持全屏完整显示。
片头支持鼠标左键或单次触摸跳过，右键、拖动和取消触摸不跳过。跳过保留退出淡出，不将此次点击交给标题或剧情。新容器表现最低Runtime0.29.0。此为当前源码能力；旧安装器不会自动获得它。
实现：OpeningAnimationEditor、OpeningScreen、openingPresentation、exportScript。

## portable-font | Windows与Android使用同一工程字体

只在作者PC安装的字体不会自动进入APK。先将有分发许可的字体文件作为字体素材导入工程，再在“客户端布局”的字体资源或具体对白/控件中绑定，导出时才会携带并加载该文件。
作者显式指定的工程字体在Windows和Android均应遵从，不按字体资源ID中的unifont、pixel、bitmap或monospace静默改用系统字体。字体缺少某些字形或浏览器无法解码时仍可能出现后备字形；需要核对具体字体文件和打包结果。当前源码修复尚不代表已生成并验收新的APK。
实现：RuntimeLayoutDesigner、exportCartridge、runtimeFont、UISkinProvider、DialogBox。
