# 标题页内置按钮样式优先级

用户确认于 2026-09-23：标题页默认按钮为纯文字，优先于项目设置；之后可在客户端布局中明确设置。

## 范围

继续游戏、开始/重新开始、存档、画廊、选项、关于这六个内置按钮默认不显示底板、图标、边框、面板阴影或模糊。文字保留可读性阴影、悬停/键盘焦点下划线；点击区域、动作、顺序和工程坐标不改变。

自定义按钮、按钮图片和外部动作不受这个默认规则影响。项目设置的标题背景、标题文本、字体和其他页面设置也不因此删除。

新增自定义标题按钮的初始配色取当前运行时主题的具体颜色值，不把编辑器 `var(...)` / `color-mix(...)` 表达式写进工程；既有自定义按钮数据不批量改写。

## 来源与兼容

- `UILayoutComponent.titleButtonStyleSource?: "layout"` 是兼容性的可选来源字段，现有 `ui_layout_version`、工程和卡带容器版本不变。
- 没有标记时，六个内置按钮使用共享 `DEFAULT_TITLE_TEXT_BUTTON_STYLE`。旧项目/主题写入的 `style` 仍原样保存在源数据中，但不会把默认标题按钮恢复成带底板的样式。
- 只有在“游戏客户端 → 标题主页”明确修改颜色、形态、字体或背景图时，才通过 `editUILayoutComponentStyle` 记录来源标记；修改从当前有效样式开始，不混入隐藏的旧底板/图片。
- 移动、缩放、选择、修改文案和几何恢复不自动启用旧样式。
- 有标记时，组件 `style` 覆盖纯文字默认；未指定的属性回落到纯文字默认。清空背景色可回到透明。
- 主题预设、主题 token 修改和恢复默认主题不能覆盖客户端布局中的标题样式。主题页标题按钮作用域显示编辑入口说明，不提供另一套会互相覆盖的控件。
- 运行时解析只创建显示副本，不回写工程；布局预览、检查器与 Runtime 使用同一共享解析函数。来源字段随显式保存、工程导出/重开、`ui/layout.json` 和卡带传递。

## 回归

- `scripts/title-text-button-style-contract.cjs`：六个默认值、旧数据保留、显式编辑、主题优先级、JSON/迁移/运行时。
- `scripts/title-text-buttons-playwright.cjs`：独立服务、真实卡带导入和真实点击；默认、旧工程、显式覆盖三组；宽/短/窄视口的样式、文字裁切、重叠、可点击与标题流程。
- `scripts/client-layout-editing-regression-playwright.cjs`：真实顶部导航编辑外观、撤销/重做、保存、重开和主题边界。
- `scripts/ui-designer-dataflow-acceptance.cjs`：实际工程 store 导入/导出保留来源标记和样式。
- `scripts/title-text-button-export-contract.cjs`：调用真实卡带和外部预览目录导出入口，核对 `ui/layout.json` 的样式与来源字段一致。

浏览器触摸仿真不代表 Android 设备通过；桌面浏览器不代表原生 GameCLI 或正式安装包通过。它们仍需最终发布矩阵的独立证据。
