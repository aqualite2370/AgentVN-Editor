# Memory Mode UI

## none

不启用长期记忆。适合短篇、测试、无连续关系剧情。

## chronicle_graph_only

只启用客观时序图谱。适合悬疑、推理、阵营关系、复杂设定。UI 中用于强调世界事实和关系一致性。

## emotion_trace_only

只启用主观情感记忆。适合恋爱、日常、角色心理、情绪变化。UI 中用于强调角色视角、误解、遗憾、亲密度和心理滤镜。

## hybrid

同时启用客观时序图谱和主观情感记忆。适合长篇、强剧情、复杂人物关系。

Toolbar 提供全局选择，Inspector 提供节点局部选择。AI 生成时节点局部设置优先。
